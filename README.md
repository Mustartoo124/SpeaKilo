# SpeaKilo

Offline, low-latency Edge-AI speech translation for frontline industrial communication on Raspberry Pi 5.

## Architecture

```
Capture -> VAD -> Audio Conditioning -> Streaming ASR -> Stable Buffer -> MT -> TTS Queue
```
